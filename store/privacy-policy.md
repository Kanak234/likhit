# Likhit — Privacy Policy
Last updated: 23 October 2026 · Contact: kanakprabhakar72@gmail.com

* **Offline OCR and Local LLM modes:** your images and text never leave your computer.
* **Cloud AI mode (only if you enter an API key and choose it):** each page image is sent to the provider you picked (OpenAI, Anthropic, Google or the OpenAI-compatible URL you typed) under that provider's own privacy terms. Likhit itself has no server and receives nothing.
* Your API key is stored in the operating system's credential store (Windows Credential Manager / Linux Secret Service) via `keyring`, never in plain files.
* No analytics, no ads, no account.
Follows India's DPDP Act 2023 and GDPR data-minimisation principles.
